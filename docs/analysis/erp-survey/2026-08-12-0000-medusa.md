# Medusa 调研报告

> **Headless 数字商务构建模块**（MIT 核心 + 企业版 RBAC）：30+ commerce 模块微服务化、workflows-sdk 长流程编排、headless/API-first。对 nop-app-erp 的 **b2b / drp 域**（电商/分销场景）与 **长流程编排设计** 有参考价值。

## 2. 核心架构（源码实测）

### 2.1 模块化微服务式架构（`packages/modules/`，30+ commerce 模块）

`product, order, cart, customer, inventory, fulfillment, payment, pricing, promotion, tax, currency, region, sales-channel, stock-location, store, user, api-key, auth, notification, file, search, analytics, settings, translation, index, locking, caching` 等

- 每模块独立领域模型 + service + 迁移；通过模块注册组合成应用

### 2.2 workflows-sdk 长流程编排（`packages/core/workflows-sdk`）

- 工作流定义（步骤 DAG）→ 编排层（`packages/core/orchestration`）执行
- 长流程（订单履约、支付→履约→配送）可暂停/恢复/补偿

### 2.3 基础设施

- 事件总线（event-bus redis/local）、查询引擎（query）、RBAC（企业版）
