# Snipe-IT 调研报告

> 最流行的开源 **IT 资产管理系统**（AGPL-3.0）：资产生命周期、折旧计算、软件许可、SCIM/LDAP/SAML 身份集成、自定义字段集。对 nop-app-erp 的 **assets 域** 有直接参考价值——特别是**折旧计算模型**与**操作审计轨迹**。

## 1. 基本信息

| 项 | 值 |
|---|---|
| 技术栈 | PHP 8.2 + Laravel 12（composer.json）· MySQL/MariaDB · Docker 部署 |
| License | AGPL-3.0 |
| 定位 | 开源 IT 资产追踪——谁有哪台设备、何时购入、折旧如何、许可归谁 |

## 2. 核心模型（源码实测 `app/Models/`）

| 模型 | 用途 |
|------|------|
| Asset / AssetModel | 资产/资产型号（型号含字段集与 EOL） |
| **Depreciation / Depreciable** | **折旧计算**（直线法、年限、按月结转） |
| Location / Company / Department / User | 组织维度 |
| License / Component / Consumable / Accessory | 许可/组件/耗材/配件 |
| Category / Statuslabel / CustomField | 分类/状态标签/**自定义字段集** |
| Maintenance / Order / PredefinedKit | 维护/采购订单/预定义套装 |

特征能力：
- **Actionlog** 操作审计轨迹（签出/签入/借出/维修全记录）
- **SCIM**（laravel-scim-server）+ LDAP/SAML 身份集成
- JSON REST API + 导入工具（ImportController）+ 标签打印（Labels）
- 资产签出/签入/借出工作流（CheckoutRequest 等）

## 3. 对 nop-app-erp 的借鉴

| # | 借鉴点 | Snipe-IT 证据 | 对 nop 的落地建议 |
|---|--------|-------------|-------------------|
| 1 | **折旧模型** | Depreciation（直线 + 按月结转） | 对照 nop assets 折旧设计（直线/工作量法 + 折旧计划→凭证）的补充视角 |
| 2 | **操作审计轨迹** | Actionlog 全操作记录 | 资产全生命周期的可审计性：与 nop 的审计日志/accounting log 衔接 |
| 3 | **自定义字段集** | CustomFieldset（按型号绑定字段） | 资产型号级扩展字段的轻量实现（对照 nop 的 ext 字段/JsonOrmComponent） |
| 4 | **身份集成（SCIM）** | laravel-scim-server | 企业身份目录（LDAP/SSO）接入参考 |
