# Twenty 调研报告

> 2023 年创立的现代开源 CRM（YC W23，25k+ stars，2026 年增长最快的开源 CRM）。TypeScript 全栈（NestJS + React + GraphQL），**对象/字段/视图以代码定义**、AI-first 设计。对 nop-app-erp 的 **crm 域现代化** 与 **GraphQL-first API 实践** 有参考价值。

## 1. 基本信息

| 项 | 值 |
|---|---|
| 技术栈 | TypeScript monorepo（NX + yarn）· NestJS（graphql-yoga-nestjs）· TypeORM · React |
| 数据库 | PostgreSQL 16 + Redis |
| License | AGPL-3.0（核心，MIT/商业双许可部分包） |
| 定位 | The #1 Open-Source CRM——给技术团队、可像代码一样版本化的 CRM |

## 2. 核心架构（源码实测）

### 2.1 对象以代码定义（defineObject SDK）

- 数据模型通过 `defineObject` SDK 以代码声明（`packages/twenty-server` 中 `@ObjectMetadata` 装饰器风格），配合 `twenty-cli app:publish` 做应用发布与版本控制
- 对比传统"数据库表即真相"——**模型版本化**是核心创新（Contact/Company/Opportunity/Note/Task 等对象）

### 2.2 GraphQL-first

- `packages/twenty-server` 基于 graphql-yoga-nestjs，REST + GraphQL 双 API，TypeORM 映射 PG

### 2.3 AI 原语

- 内建 **Agents 与 Workflows** 一等公民原语；AI assistant（chat with CRM data）、自动补全联系人、邮件摘要

### 2.4 生态包

- `twenty-emails`（邮件同步 Gmail/IMAP）、`twenty-zapier`（Zapier 集成）、`twenty-docker`（自托管）、`twenty-client-sdk` / `twenty-sdk`

## 3. 对 nop-app-erp 的借鉴

| # | 借鉴点 | Twenty 证据 | 对 nop 的落地建议 |
|---|--------|-------------|-------------------|
| 1 | **对象以代码定义 + 版本化** | defineObject SDK + app:publish | 与 nop 的模型驱动（orm.xml 唯一真相）对照——nop 的 XML 亦是可版本化的代码式模型，理念一致、实现更彻底 |
| 2 | **GraphQL-first 统一 API** | graphql-yoga-nestjs + TypeORM | Nop 已自动暴露 GraphQL（IGraphQLEngine），无需改动；可对照其 schema 组织 |
| 3 | **AI 作为 CRM 一等公民** | Agents/Workflows 原语 + chat with data | 若 crm 域引入 AI 助手，参考其"原语化"而非外挂化做法 |
| 4 | **乐观更新 SPA 体验** | 前端快速 UI（SPA, optimistic updates） | 对照 AMIS 渲染下的交互范式 |
