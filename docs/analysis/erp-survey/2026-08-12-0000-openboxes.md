# OpenBoxes 调研报告

> 起源于 Partners In Health 的海地地震医疗物资分发，现服务全球医疗/通用供应链的**开源仓库与库存管理（WMS）系统**（EPL-1.0）。核心参考价值：**库存审计与快照、周期盘点、批次/序列追踪、补货/预约/履行闭环**——对口 nop-app-erp 的 inventory 域纵深。

## 1. 基本信息

| 项 | 值 |
|---|---|
| 技术栈 | Groovy/Grails（grails-app/）· Webpack 前端 · MySQL/MariaDB（Liquibase 迁移） |
| License | Eclipse Public License 1.0 |
| 定位 | 开源仓库与库存管理（WMS），面向低资源环境高效运行 |

## 2. 业务域（源码实测 `grails-app/domain/org/pih/warehouse/`）

| 域 | 核心实体 |
|----|---------|
| inventory | InventoryItem、InventorySnapshot（**库存快照**）、InventoryAudit（**审计**）、CycleCountTask（周期盘点）、StockMovement |
| product | Product、ProductPackage、**lot/serial 批次序列追踪** |
| order | Order、OrderItem、采购补货（Requisition） |
| shipping | Shipment、ShipmentItem、接收（Receiving）、履行（Fulfillment） |
| picklist | Picklist（拣货单）、PickListItem |
| forecasting | 需求预测 |
| core | Location、BinLocation、Organization |

服务层（`services/`）同名配套：`inventory,order,picklist,product,putaway,receiving,replenishment,report,requisition,shipping,stockTransfer,glAccount` 等——**补货（replenishment）、上架（putaway）、库间调拨（stockTransfer）** 是 WMS 特征能力。

## 3. 对 nop-app-erp 的借鉴

| # | 借鉴点 | OpenBoxes 证据 | 对 nop 的落地建议 |
|---|--------|-------------|-------------------|
| 1 | **库存审计与快照模式** | InventoryAudit + InventorySnapshot | 盘点/审计场景：nop 的 3 层模型（Move→Ledger→Balance）可对照快照语义做期末对账 |
| 2 | **周期盘点工作流** | CycleCountTask | 对照 nop inventory 的盘点设计，补充周期化任务视图 |
| 3 | **补货-拣货-上架-调拨闭环** | replenishment/picklist/putaway/stockTransfer | WMS 特征服务拆分的模块边界参考 |
| 4 | **批次/序列全链路** | lot/serial 在出入库/调拨/盘点贯穿 | 对照 nop 的批次追溯链设计 |
