## §1 需求契约原文（L1，逐字引用 `docs/design/aps/use-cases.md`）

> L1 逐字引用验收标准原文（禁止转述，§1 L1 格式）。每个 UC 的验收标准逐条进入 §5 L5 判读。

### UC-APS-01 工序工单创建（从主工单）（`use-cases.md:3-13`）
- 基本流程：「1. manufacturing 域发布 WorkOrder 下达事件 2. APS 域订阅，读取 WorkOrder 的工艺路线（工序列表） 3. 按 sequence 依次创建每条工序的 OperationOrder（status = DRAFT） 4. 继承 workOrderId、operationName、machineId、setupTime、runtimePerUnit、qty 5. 计算 totalDuration = setupTime + runtimePerUnit × qty」
- 异常：「工艺路线缺失时跳过并告警；工作中心不存在时拒绝创建」
- 跨域协作：「manufacturing（读取 WorkOrder 和工艺路线）」

### UC-APS-02 前向排产（`use-cases.md:15-25`）
- 基本流程：「1. 选择待排产的 OperationOrder（可筛选 WorkOrder/工作中心/时间段） 2. 系统按优先级（priority）+ sequence 排序 3. 从 WorkOrder.plannedStartDate 或当前时间开始正向填充 4. 同一工作中心同一时间只安排一个工序（有限产能约束） 5. 相邻工序之间预留换模/清理时间 6. 每个 OperationOrder 的 plannedStartDateT/plannedEndDateT 写入 7. status→PLANNED」
- 异常：「产能不足时系统标记冲突，等待计划员手动调整」
- 跨域协作：「读取 maintenance/downtime 约束（ErpApsConstraint）」

### UC-APS-03 后向排产（`use-cases.md:27-37`）
- 基本流程：「1. 从 WorkOrder.requiredEndDate 出发逆向推算每个工序的结束时间 2. 同一工作中心从后向前检查空闲时段 3. 计算每道工序的最晚开工时间 4. 若最终最晚开工时间早于当前时间，标记"无法按期交付"」
- 异常：「交期不可达时告警，建议计划员改为前向排产并通知销售」
- 跨域协作：「sales（读取客户交期）」

### UC-APS-04 插单/急单插入（`use-cases.md:39-49`）
- 基本流程：「1. 计划员创建急单 OperationOrder，设置低 priority（数字小 = 优先级高） 2. 系统检测新单预计插入时间窗口 3. 仅将受影响的 OperationOrder（时间窗口内且优先级低于新单）回退到 DRAFT 4. 不影响窗口外的 OperationOrder（避免牛顿效应） 5. 执行区间重排，所有受影响工序重新写入 plannedStartDateT/plannedEndDateT」
- 异常：「若受影响工序已 IN_PROGRESS，不可重排，需人工决定」

### UC-APS-05 ATP/CTP 交期承诺（`use-cases.md:51-61`）
- 基本流程：「1. 销售订单审核触发 ATP/CTP 请求 2. APS 域接收物料 + 数量 + 期望交期 3. 创建"影子"OperationOrder（不持久化） 4. 在现有排产方案上模拟排产（考虑产能占用） 5. 前向排产 计算最早可交付日期（ATP） 6. 或后向排产 按期望交期检查产能是否足够（CTP） 7. 返回结果给销售域 最早交付日期或"交期可行"」
- 异常：「产能不足时返回建议交期（最早可用时间）」
- 跨域协作：「sales（ATP/CTP 接口）；master-data（物料/工艺路线）」

### UC-APS-06 替代工艺路线（`use-cases.md:63-73`）
- 基本流程：「1. 计划员配置工序的替代路由（ErpApsOpRouting），设定优先级、换模时间差、单件加工时间差 2. 排产引擎在分配工作中心时，按 priority ASC 依次检查路由可用性 3. 如主选（isDefault=true）可用则使用主选；如主选产能不足则自动尝试备选 4. 选中的路由回写操作工单的 selectedRoutingId 5. 如全部路由不可用则标记为 UNSCHEDULABLE 6. 计划员可强制指定某条路由（manualOverride）」
- 异常：「所有备选路由均不可用时工序标记为不可排产并告警」
- 跨域协作：「scheduling（排产引擎调用路由选择逻辑）；manufacturing（工艺路线/BOM）」

### UC-APS-07 自动派工（`use-cases.md:75-85`）
- 基本流程：「1. 配置工作中心的自动派工规则（ErpApsDispatchRule）：打开/关闭自动派工、条件检查开关、前瞻窗口等 2. 自动派工引擎周期性扫描 PLANNED 工序，检查 plannedStartDateT 在窗口内 3. 按规则检查物料齐套、操作工可用、工装可用 4. 全部条件满足 → OperationOrder.status=IN_PROGRESS，记录 ErpApsDispatchLog 5. 条件不满足则跳过（等待下一轮） 6. 计划员可手动强制派工（跳过条件检查）或将工序置为 HOLD 暂不派工」
- 异常：「自动派工后发现物料不足 → 工序暂停（ON_HOLD）并通知计划员」
- 跨域协作：「inventory（物料齐套检查）；manufacturing（创建 JobCard 开始报工）」
