## 1. 需求契约原文（L1 逐字引用）

> 逐字引用 `docs/design/drp/use-cases.md` UC-DRP-01~08 验收标准（锚点 = UC 编号 + 逐字原文）。

### UC-DRP-01 DRP 计划创建（`use-cases.md:3-13`）
- 基本流程：「1. 创建 ErpDrpPlan，填写 planName、periodFrom、periodTo」「2. 初始状态为 DRAFT」「3. 可选关联特定的仓库/物料范围（若不指定则全量）」「4. 保存」
- 后置条件：「DRAFT 计划的 DrpPlan 记录已创建」
- 异常：「时间段重叠告警（可选，同一期间允许创建多版本方案）」

### UC-DRP-02 净需求计算（DRP 运行）（`use-cases.md:15-25`）
- 基本流程：「1. 读取范围内每个物料+仓库组合的 ErpDrpParameter」「2. 从库存模块读取 currentStock、allocatedQty、onOrderQty」「3. 从销售预测读取 forecastDemand（或使用默认值 0）」「4. 计算 netRequirement = max(0, safetyStock + forecastDemand - currentStock + allocatedQty - onOrderQty)」「5. 若 netRequirement > 0，向上取整到 orderMultiple 倍数 → suggestedQty」「6. 根据 preferredSourceWarehouseId 或 preferredSupplierId 确定 replenishmentType」「7. 生成 ErpDrpLine（status = SUGGESTED）」「8. 更新 DrpPlan.totalReplenishmentQty、runAt、runBy」「9. DrpPlan.status → COMPUTED」
- 异常：「物料参数缺失时跳过并告警；netRequirement ≤ 0 时不生成行（库存充足）」
- 跨域协作：「inventory（读取库存数据）；？sales/forecast（读取预测）」

### UC-DRP-03 补货建议审批（`use-cases.md:27-37`）
- 基本流程：「1. 计划主管打开 COMPUTED 的 DRP 计划」「2. 逐行或批量审查 SUGGESTED 的补货建议」「3. 可调整 approvedQty（修改 suggestedQty 或直接设为 0 取消）」「4. 确认后批准 → DrpLine.status = APPROVED」「5. 所有行审批完成后 DrpPlan.status → APPROVED」「6. 或在 COMPUTED 发现数据异常时回退到 DRAFT（重新计算）」
- 异常：「仅部分行批准时，未批准行保持 SUGGESTED 或手动置为 CANCELLED」

### UC-DRP-04 自动生成补货单（`use-cases.md:39-49`）
- 基本流程：「1. 系统遍历所有 APPROVED 的 DrpLine」「2. 根据 replenishmentType 执行 — TRANSFER → 调用 inventory/transfer 创建 TransferOrder（源仓库→目标仓库，数量=approvedQty）/ PURCHASE → 调用 purchase 创建 PurchaseOrder（首选供应商，物料，数量=approvedQty）」「3. 补货单创建成功后回写 orderBillType/orderBillCode」「4. DrpLine.status → ORDERED」「5. 所有行完成后 DrpPlan.status → EXECUTED」
- 异常：「补货单创建失败时该行标记错误并重试；已生成补货单的行不可重复生成」
- 跨域协作：「inventory/transfer（调拨单创建）；purchase（采购单创建）」

### UC-DRP-05 安全库存调整（`use-cases.md:51-61`）
- 基本流程：「1. 选择仓库和物料组合」「2. 查找或创建 ErpDrpParameter」「3. 编辑参数 safetyStock、replenishmentLeadTime、orderMultiple、replenishmentMethod」「4. MIN_MAX 方法时设置 minStockLevel/maxStockLevel」「5. PERIODIC 方法时设置 reviewPeriodDays」「6. 保存」
- 异常：「参数值校验（safetyStock > maxStockLevel 时告警；orderMultiple 必须为整数或倍数）」

### UC-DRP-06 安全库存优化（`use-cases.md:63-73`）
- 基本流程：「1. 选择物料和仓库，配置分析方法（STATISTICAL/SIMPLE/DDMRP）、服务水平、分析月数、提前期」「2. 系统读取历史期间的需求数据，计算平均需求与标准差」「3. 按公式 Z×σ×√L 计算建议安全库存和再订货点」「4. 结果写入 ErpInvDrpSafetyStockCalc.calculatedSafetyStock/calculatedRop」「5. 人工审查后可覆盖（overrideSafetyStock），确认后回写 ErpDrpParameter.safetyStock」「6. 下次 DRP 运行时使用更新后的安全库存参数」
- 异常：「历史数据不足时降级使用 SIMPLE 方法；计算结果差异超过阈值（默认 20%）时告警」

### UC-DRP-07 越库（Cross-Dock）（`use-cases.md:75-85`）
- 基本流程：「1. DRP 计划行标记 crossDockFlag=true 或 ASN 入站识别越库标记」「2. 创建 ErpInvDrpCrossDock（status=PENDING）」「3. 货物入站到越库暂存区（status=STAGING）」「4. 系统按策略（PRE_ALLOCATED/ON_RECEIPT/MANUAL）匹配目标出库订单」「5. 匹配成功（status=MATCHED），生成出站移动单，装车（LOADED）」「6. 出库确认后完成（COMPLETED）」「7. 月台预约（ErpInvDrpDockAppointment）管理到货时间窗口」
- 前置条件：「越库功能已启用（erp-inv.drp-xdock-enabled=true）；仓库已配置越库暂存区」
- 异常：「超时未匹配（默认 24h）自动转为正常入库；物料需质检时在暂存区完成快检」
- 跨域协作：「inventory（StockMove 入站/出站）；purchase（采购单收货标记越库）；sales（匹配销售订单出库）」

### UC-DRP-08 提前期跟踪与动态安全库存（`use-cases.md:87-97`）
- 基本流程：「1. 采购订单收货确认时系统自动计算 actualLeadTime = DATEDIFF(receiptDate, orderDate)」「2. 创建 ErpInvDrpLeadTimeRecord，记录 supplierId、materialId、orderDate、receiptDate、actualLeadTime、expectedLeadTime、isOnTime」「3. 统计分析任务按供应商+物料维度计算 μ、σ、准时率、变异系数」「4. 与安全库存优化模块联动：当提前期变异高（σ/μ > 0.2）时使用联合变异公式计算安全库存」「5. 分析结果可用于动态更新 ErpDrpParameter.replenishmentLeadTime 和 safetyStock」「6. 供应商可靠性评分按准时率、稳定性、数量准确率、质量合格率综合计算」「7. 评分等级影响安全库存调整幅度和补货策略」
- 异常：「订单日期或收货日期缺失时不记录（跳过告警）；历史数据不足（<5 笔）时统计结果仅供参考」
