# Lesson 22: 收官断言必须覆盖门控全表——「只盯上轮漂移维度」的断言窄化陷阱

> **来源**：2026-09 ai-check-r3 mission（MV.3 移交点名候选「R1b/R1d 三元断言新失败模式」，plan `2026-09-11-0906-3` → 本课落盘 plan `2026-09-11-1425-1` MG.1）。证据基 = M2.9 收官阻塞披露（plan `2026-09-11-0457-1` Phase 3 + 本轮索引 §M2.9 收官注记）与 F2.9 既有漏检（plan `2026-09-09-2100-1` 裁决）。
> **适用场景**：任何存在**机器门控全表**（compliance checker 19 规则、CJK `--strict`、i18n-coverage、全 reactor 测试）的批次/计划收尾——凡门控有 N 个维度，收官断言就有 N 个必检项。
> **失败模式**：收尾断言清单只复检「上轮漂移过的维度」（三元断言），门控其余维度整轮无人看——新漂移必然漏网，且每轮收尾都产出「零漂移」的**假阴性绿**。

## 核心论点

**断言范围必须与门控面同构。** 门控表有 19 条规则，收尾却只断言 3 条「曾经漂过的」——这不是省事，是把门控退化成「只巡逻上次失窃的窗户」：小偷换一扇窗就全数漏网。「上轮漂移过的维度」是**结果**，不是**风险面**；风险面由门控全表定义，不由历史定义。

## 失败模式（典型路径）

```
1. 批次 P1 引入规则 X 漂移 → 全表复跑暴露 → 裁决闭合
2. 后续批次收尾把断言清单写成「X/Y/Z 持平」（仅历史漂移三元）
3. 新代码在维度 Y 引入新漂移——收尾断言不覆盖 Y → 绿
4. 漂移穿越多轮收尾，直到收官全表同跑（或 CI live red）才暴露
5. 此时已积压多批，归因与裁决成本放大
```

## 真实案例（r3 两起独立实例）

### Case A: R1b/R1d 三元断言漏检（穿越 M2.5~MV.1）

- M2.5 修复批 commit `48b57cd06`（机器块冻结 `060ddab0a` 之后）在 `ErpInvSerialNumberBizModel.java` 引入 R1b=1>0 + R1d=15>14 漂移。
- M2.5~M2.8 四个批次收尾均只断言 R2b/R2c/R12a 三元 → 四轮「零漂移」假阴性绿。
- M2.9 收官 checker **全表同跑**才暴露（plan `2026-09-11-0457-1` Phase 3，登记收官阻塞），successor `m29-r1b-r1d-baseline-adjudication`（plan `2026-09-11-0906-1`）全表复跑闭合：R1b Fix 回落=0 + R1d 14→15 per-site raise 双写，checker exit 0（R1b=0/R1d=15/R2b=242/R2c=1543/R12a=71）。
- 反向对照：同 mission 审计侧 28/28 切片全部执行「checker 19 规则逐项 = M0.3 快照行」**全表**断言——同一 mission 内审计侧全表、修复侧三元，落差即陷阱本体。

### Case B: F2.9 closure 仅核 daoFor 漏 R12 import 面

- commit `0a825a42a`（F2.9）closure 声称「checker 零漂移」，实际只核 daoFor 一条规则，漏掉 R12 import 面——R12a 70→71 恰是该漏检（MI.3 才暴露）。
- 处置：`compliance-baseline.md` 增立行规——**R12 import 面与 daoFor 并列为生产代码变更 closure 必检项**（把断言清单显式对齐门控全表）。

## 收尾协议

1. 列出本项目全部机器门控维度（checker 全表 / CJK `--strict` / i18n-coverage / 全 reactor test）。
2. 收官断言 = 门控全表逐维度断言，**禁引用「上轮漂移清单」充当断言范围**。
3. 断言写法禁「X/Y/Z 持平」省略式——写「全表 actual ≤ 机器块 exit 0 + 逐值清单」。
4. 「本轮没碰某维度所以不查」的推理无效：漂移恰恰来自没碰的维度（R1b/R1d 均系 M2.5 修复义务的非目标维度）。
5. 发现穿越性漂移：按 lesson 07 决策树 per-site 裁决（Fix vs raise），走独立裁决计划，不就地放宽。

## 自检清单（批次/计划收尾前）

- [ ] 本项目机器门控全表列全了吗（几条规则/几个 checker）？
- [ ] 收官断言是否逐维度覆盖全表，而非仅「上轮漂移三元」？
- [ ] 断言证据是否为逐值清单（可机械复核），而非「零漂移」口头结论？
- [ ] 若确要省时只复跑部分维度：是否有独立全表复跑兜底（收官/CI）且其结果会回灌本批收口？
