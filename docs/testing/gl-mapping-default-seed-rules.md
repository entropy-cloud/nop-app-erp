# GL 映射规则默认种子（accountKey → targetSubjectCode）

> Plan: `docs/plans/2026-07-24-1351-1-gl-mapping-provider-rollout.md` Phase 4。
> 用途：28 routing Provider 接入键的**代表性 default 规则**基线（priority=0、全 NULL 维度、
> `targetSubjectCode` = Provider 既有 fallback 编码）。运维可按此 CSV 导入 erp_fin_gl_mapping_rule
> 作为兜底规则（与 Provider 既有行为等价），再按需追加精确规则（priority≥100 + 具体维度）覆盖。
>
> 命中路径已在测试中验证：`TestErpFinGlMappingResolver`（PURCHASE/MANUFACTURING_WIP 命中 + NOTES_RECEIVABLE 未命中 null）
> + `TestErpPurInvoicePosting.testGlMappingRuleOverrideChangesSubjectCode`（AP_INVOICE 3 键端到端覆盖）。
