  - **C4** 任意状态计划：阶段节（`### Phase …` 至下一节标题）内 `Status: completed` 但节内存在 `- [ ]` = 勾选失真违规（guide 规则 11 文本一致性）；

- 基线快照机制（lesson 20 要素 3/5，Decision-1）：`docs/audits/plan-gates-baseline.md` 机器可读 SNAPSHOT 块（per-file per-检查类违规计数 + 三条头注：勿手改/`--baseline` 整体重生成/误改可 `git checkout` 还原复验 + IMPROVEMENTS 仅报告永不自动改写快照；注记并列**存量全类清单**：C1 8 文件（f38 类补勾 / f310·01-product-grade 类需重审分档）/ C2 违规文件清单与证据形态分档 / C4 2 文件 3 节 / C5 ~55 文件清单——冻结时实测填充）；`--baseline` 重生成；`--strict` 断言 `actual ≤ snapshot`，新增未登记违规非零退出，改进列 IMPROVEMENTS 提示（仅报告，永不自动改写快照）。
