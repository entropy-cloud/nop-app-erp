  - **UC-APS-04 插单/急单插入**（`:39`）：建急单 OperationOrder 设高优先级（低 priority 数字）→ 检测插入时间窗口 → 仅受影响 OperationOrder（窗口内且优先级低于新单）回退 DRAFT → 不影响窗口外（避免牛顿效应）→ 区间重排写时间；异常：受影响工序已 IN_PROGRESS 不可重排需人工决定。
  - **UC-APS-05 ATP/CTP 交期承诺**（`:51`）：销售订单审核触发 ATP/CTP → APS 接收物料+数量+期望交期 → 创建"影子"OperationOrder（不持久化）→ 在现有方案上模拟排产 → 前向计算最早可交付(ATP)/后向按交期检查产能(CTP) → 返回最早交付日期或"交期可行"；异常：产能不足返回建议交期；跨域：sales/master-data。
  - **UC-APS-06 替代工艺路线**（`:63`）：配置 ErpApsOpRouting（主选+备选 priority/换模时间差/单件加工时间差）→ 排产引擎按 priority ASC 检查路由可用性 → 主选可用用主选/主选产能不足自动尝试备选 → 选中回写 selectedRoutingId → 全部不可用标 UNSCHEDULABLE → 计划员可强制指定(manualOverride)；异常：全备选不可用告警；跨域：scheduling/manufacturing。
  - **UC-APS-07 自动派工**（`:75`）：配置 ErpApsDispatchRule（开关/条件检查/前瞻窗口）→ 引擎周期扫描 PLANNED 工序检查 plannedStartDateT 在窗口内 → 按规则检查物料齐套/操作工可用/工装可用 → 全满足 status=IN_PROGRESS 记 ErpApsDispatchLog → 不满足跳过 → 计划员可手动强制派工/置 HOLD；异常：派工后发现物料不足工序 ON_HOLD 通知计划员；跨域：inventory（物料齐套）/manufacturing（创建 JobCard 报工）。
